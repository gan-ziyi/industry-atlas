# Industry Atlas 正式 Web 版

这是从原生 HTML 原型迁移出的 React + TypeScript 正式前端。旧原型仍保留在项目根目录，用于迁移尚未覆盖的高级交互。

## 本地运行

```powershell
cd web
pnpm install
pnpm dev
```

浏览器打开 `http://127.0.0.1:5173`。生产构建使用：

```powershell
pnpm build
pnpm preview
```

## 已迁移能力

- React Flow 产业图谱、缩放、拖拽、节点选择和小地图；
- 节点研究卡片编辑、自动保存和新增下级环节；
- 旧版浏览器工作区数据自动迁移；
- 研究完整度看板与缺口跳转；
- 公司档案、产业映射审核、多期经营发现和多公司选择；
- 后端文件任务读取；
- PDF 原始上传、解析轮询与首段原文回填；
- DeepSeek 年报结构化提取、分类筛选、页码原文匹配和人工选择写回；
- AI 发现同步写入节点证据、公司档案、报告期和产业映射候选；
- 正式版手动/自动快照、历史列表和恢复前备份；
- Word、Excel、PDF 精准导出；
- 正式版内置后端连接检查、邮箱注册/登录、开发登录和退出登录，不再依赖旧原型建立会话；
- 团队与权限页面支持 owner 邀请已有账号、切换 editor/viewer 角色和移除成员；
- 项目同步采用版本号乐观锁；发生多人编辑冲突时明确比较本地/云端摘要，并由用户选择使用云端或覆盖云端；
- 云端项目中心支持研究空间切换、项目列表、打开已有项目、基于当前草稿新建项目和删除项目；
- 本地草稿与快照按账号、研究空间和项目分区保存，旧版数据只进行一次兼容迁移；
- viewer 会进入明确的只读模式，不能拖动节点、编辑研究卡、调用 AI 或同步修改；
- 节点证据可新增、编辑、删除并单独标记人工核验；
- 扫描型 PDF 可从文件任务直接启动本地 OCR；
- 年报表格可预览、切换、下载 CSV 并写入当前产业节点；
- 产业图谱 AI 支持“继续拆解”和“完善内容”，只接受结构化补丁；
- AI 修改按新增节点、修改内容和新增关系逐项展示，包含修改前、修改后和理由，可选择性接纳；
- 研究任务支持新增、编辑、删除、状态推进，以及按研究缺口批量生成；
- 项目与工作空间公司主档同步；
- 统一 TypeScript 产业、公司、证据、任务与文件类型。

## 数据与后端

正式版复用原型的后端 URL、登录会话和工作空间配置。项目状态另存为 `industry-atlas-formal-workspace-v1`，不会覆盖旧原型数据。首次打开时，如果正式版没有数据，会尝试迁移 `industry-atlas-workspace-v1`。

正式账号密码只在后端保存加盐后的 scrypt 哈希。开发登录仍仅适合本机验证，生产部署必须关闭。云端项目 ID 与版本号保存在浏览器本地，登录令牌只保存在当前会话。登录后可从“云端项目”切换本人拥有或受邀加入的研究空间，并重新打开云端项目。
