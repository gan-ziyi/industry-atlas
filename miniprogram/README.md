# Industry Atlas 微信小程序版

这是复用 Industry Atlas 正式 Web 后端的原生微信小程序客户端。当前版本已经形成完整的移动研究闭环：

- 微信 `wx.login` 与后端 `code2Session` 凭证交换；
- 本地体验、邮箱注册/登录、微信登录，以及邮箱账号绑定微信；
- 多研究空间切换和 owner/editor/viewer 权限；
- 云端项目列表、新建、打开、重新载入和删除；
- 适合手机的产业链层级视图、搜索、展开与收起；
- 节点解释、证据、指标、瓶颈和关联公司查看；
- editor/owner 可编辑节点名称、分类、解释、指标和瓶颈，增加或安全删除产业节点；
- 手工证据、年报证据、人工核验和页码级引用；
- 小程序内新建研究任务、关联节点、设置优先级和推进状态；
- 项目版本同步与本地/云端冲突选择；
- viewer 明确只读，不能编辑或同步覆盖。
- 从微信聊天文件选择 PDF、查看页数/字符/表格与解析状态，并启动本地 OCR；
- 发起 DeepSeek 年报结构化提取，在手机上逐条审核原文匹配结果并写入指定产业节点和公司档案；
- DeepSeek 新建产业图谱、对现有图谱提出补丁、逐项展示修改前后内容并选择性接纳；
- 公司档案、产业节点映射、候选确认/排除和手工映射；
- 研究空间成员邀请、owner/editor/viewer 权限调整；
- Word、Excel、PDF 精准导出，并通过微信文件菜单保存或转发。

## 在微信开发者工具中运行

1. 导入本目录，开发阶段可使用 `project.config.json` 中的游客 AppID；游客 AppID 只能使用模拟器，不能生成真机预览码；
2. 本地联调时在“详情 → 本地设置”勾选“不校验合法域名”；
3. 在登录页填写后端地址。开发者工具可使用 `http://127.0.0.1:8000`；真机必须使用已备案的 HTTPS 域名；
4. 可以使用“本地体验”，也可以在小程序内注册邮箱账号；
5. 微信登录需要在后端 `.env` 配置 `WECHAT_APP_ID` 和 `WECHAT_APP_SECRET`，同时把 `project.config.json` 的 AppID 替换为真实小程序 AppID。

微信 AppSecret 和 DeepSeek Key 都只能配置在后端，不能写入小程序代码。设置页会显示两项服务是否已配置，但不会返回或展示密钥。

## 静态检查

```powershell
node check.mjs
```

该检查会验证页面文件、JSON、JavaScript 语法、WXML 事件绑定、浏览器专属 API 误用和密钥痕迹。完整交互与真机网络仍需使用微信开发者工具验证。

## 正式发布边界

代码层已经完成。发布到微信前仍需要平台侧资源：正式小程序 AppID、已备案 HTTPS API 域名、微信后台 request/uploadFile/downloadFile 合法域名，以及部署后的后端、数据库和文件存储。详见项目根目录的 `MINIPROGRAM_RELEASE.md`。
